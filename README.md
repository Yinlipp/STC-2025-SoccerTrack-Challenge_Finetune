# STC-2025-SoccerTrack-Challenge_Finetune
Fine-tuned baseline code for the SoccerTrack Challenge 2025 (STC-2025), designed for beginners.

## Overview
Fine-tune YOLOv11 + Deep-EIoU

To improve player tracking performance in the STC-2025 competition, we introduce a baseline that uses YOLOv11 fine-tuned on the STC-2025 training dataset as the detector, 
combined with the tracking algorithm from DeeP-EIoU.

## How to Use
### 1.Enviroment Setup
Create an environment that supports both Deep-EIoU and YOLOv11, with Python=3.8.

Please refer to following official github introductions:

- [Deep-EIoU](https://github.com/hsiangwei0903/Deep-EIoU)
- [YOLOv11](https://github.com/ultralytics/ultralytics)

### 2.Fine-tune YOLOv11
The official website provides a detailed description, https://docs.ultralytics.com.

#### Dataset
The YOLO fine-tuning dataset needs to be organized according to the specified structure, as shown in the diagram below:

```
dataset/
├── images/
│   ├── train/
│   │   ├── img1.jpg
│   │   ├── img2.jpg
│   │   └── ...
│   └── val/
│       ├── img1.jpg
│       ├── img2.jpg
│       └── ...
├── labels/
│   ├── train/
│   │   ├── img1.txt
│   │   ├── img2.txt
│   │   └── ...
│   └── val/
│       ├── img1.txt
│       ├── img2.txt
│       └── ...
└── data.yaml  ← content：
       train: dataset/images/train
       val: dataset/images/val
       nc(number of classes）: 1
       names: ['player']
```

Using Script [STC/dataset_creation.py](https://github.com/Yinlipp/STC-2025-SoccerTrack-Challenge_Finetune/blob/main/STC/dataset_creation.py), 
the fine-tuning dataset is automatically generated by dividing the data into training and validation sets at a 7:3 ratio.

refers to the constructed fine-tuning YOLOv11 custom dataset.
```
STC/STC_YOLO_finetune_dataset
```

Download the STC-2025 training set here
```
STC/Training_dataset
```

### 3.Modify Deep-EIoU
Deep-EIoU uses YOLOX as the default detector. To use the fine-tuned YOLOv11, it is necessary to modify the Deep-EIoU/tools/demo.py

First, a new script was developed to define and invoke the custom YOLOv11Detector class for integrating the fine-tuned YOLOv11 at [Deep-EIoU/Deep-EIoU/tracker/yolov11_det.py](https://github.com/Yinlipp/STC-2025-SoccerTrack-Challenge_Finetune/blob/main/Deep-EIoU/Deep-EIoU/tracker/yolov11_det.py). 

Subsequently, the relevant parts of [Deep-EIoU/Deep-EIoU/tools/demo.py](https://github.com/Yinlipp/STC-2025-SoccerTrack-Challenge_Finetune/blob/main/Deep-EIoU/Deep-EIoU/tools/demo.py) script were modified. 
The changes are marked with # modification point comments. For details, please refer to the code.

### 4.Running Tracking on a Video
You can run the Deep EIoU framework with the fine-tuned YOLOv11 by executing the following command:
```
python tools/demo.py --path <video_path> --detector yolov11 --det_ckpt <fine-tuned YOLOv11 best.pt path>
```

The tracking results will be generated under ‘Deep-EIoU/Deep-EIoU/YOLOX_outputs/yolox_x_ch_sportsmot/track_vis/<timestamp>.txt.’
By modifying the starting frame number to 1 and replacing all commas with spaces, the output will conform to the MOT format required by the competition.
